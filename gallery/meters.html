sparks vs fill meters

Two jobs. Tmux cpu/mem is a history spark (8 samples, height = value). Claude context is a fill tank (how full right now). We used fat braille for both. Braille is a skyline. A tank should fill left to right.

Peach dashed = live. Mauve solid = what I’d pick. Same fake cpu history: 8 18 45 80 62 30 22 40. Hack draws the block elements; nerd draws the circles. If a row is tofu, the font doesn’t have it.
